# Bundled bridge installer

This directory is served by Frappe at `/assets/alphax_pos_suite/bridge/`.

Contents, both generated by `scripts/sync_bridge_kit.ps1`:

    AlphaX-POS-Bridge-Setup-<version>.zip   the kit (~72 KB)
    manifest.json                            version + sha256

Do not hand-edit either. Re-run the sync script against a bridge tag.

Keep exactly ONE kit zip here. The sync script deletes older ones; if two
ever coexist, `manifest.json` decides which is served and the other is
dead weight in every clone forever.

## Why the zip is committed

It is a build artefact, which normally does not belong in git. It is here
because Frappe Cloud builds on Linux and cannot produce or fetch this at
deploy time, and because a shop with no route to GitHub still has to be
able to install the bridge. 72 KB per bridge release is an acceptable
price for "the site serves its own hardware driver".
